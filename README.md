##  Proyectos destacados

### [MammoClasification](https://github.com/Turris20/MammoClasification) · Deep learning en imagen médica
Clasificador benigno/maligno de mamografías entrenado sobre seis bases públicas con **Multiple Instance Learning y atención** (ConvNeXt + CBAM, PyTorch). Detecté fuga de pacientes en las particiones originales y que la fuente de los datos servía de atajo, y demostré que las etiquetas por paciente limitaban el rendimiento más que el modelo.
**AUC 0.829** en un conjunto de prueba sin fuga · artículo en preparación en el laboratorio LIIACOM (UACH).

### [CKD-classification](https://github.com/Turris20/CKD-classification) · Machine learning desde cero
Calculadora de enfermedad renal crónica con interfaz gráfica que compara **tres clasificadores implementados a mano** en GNU Octave: Naive Bayes gaussiano, red neuronal con *backpropagation* propio y un clasificador lineal.

### [HealthSync](https://github.com/Turris20/HealthSync) · Desarrollo full-stack
Prototipo web de monitoreo de signos vitales: API REST en **Express + MongoDB**, un simulador de sensores y un dashboard en **Next.js** que se actualiza automáticamente.

### [MotionMates](https://github.com/casvaz/motionmates) · Aplicación de escritorio (en equipo)
App en **Python + Flet** que guía rutinas de fisioterapia para pie, rodilla y cadera, con más de 40 pantallas y un tutorial para medir el ángulo de flexión de la rodilla.
